# Go Learning Lab

Учебный репозиторий для повторного изучения Go и постепенного восстановления понимания проекта ShareTrip.

Вместо второго полноценного микросервиса здесь будет небольшой проект **MeetupLite**: создание встречи, получение встречи и публикация встречи. Он будет развиваться от чистого Go и in-memory хранения до HTTP, PostgreSQL, транзакций и наблюдаемости.

## Правила обучения

- Один урок — одна основная идея и один небольшой коммит.
- Сначала самостоятельная попытка, затем подсказка или ревью.
- Готовый код не переносится из ShareTrip.
- Каждый новый механизм нужно уметь объяснить без открытого редактора.
- Fiber, Docker и PostgreSQL добавляются только после понятного варианта на стандартной библиотеке.
- Метрики и логирование изучаются последними.

Подробная последовательность находится в [LEARNING_PLAN.md](LEARNING_PLAN.md).

Первый урок начнём с пакетов, значений, типов и функций. Учебный код намеренно пока не добавлен: его нужно написать вместе, а не получить готовым.
