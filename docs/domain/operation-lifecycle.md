# Жизненные циклы команды и Operation

> Статус: промежуточный учебный артефакт S02.

`RecordOperationCommand` и `Operation` описывают разные вещи. Команда выражает просьбу пользователя записать финансовый факт и может завершиться без создания операции. `Operation` появляется только после успешного append.

## RecordOperationCommand

```text
получена → проверяется → выполнена
                      ↘ отклонена
                      ↘ technical failure
```

- Отклонённая команда нарушила validation или бизнес-правило. Журнал не меняется.
- Technical failure означает, что система не смогла надёжно завершить обработку.
- Если сбой произошёл во время append, клиент может не знать результат. Безопасный повтор с тем же идентификатором должен восстановить сохранённый ответ либо выполнить ещё не завершённую команду.

## Operation

```text
не существует → appended → остаётся неизменяемой
                              ↑
                 компенсация добавляется отдельно
```

У `Operation` нет состояний `pending`, `rejected` или `cancelled`:

- до append существует команда, но ещё не операция;
- rejection является результатом команды и не создаёт операцию;
- принятая операция не изменяется и не удаляется;
- исправление создаёт отдельную `CompensatingOperation`;
- признак того, что эффект исходной операции компенсирован, вычисляется по связи записей, а не меняет исходную запись.

Если продукт когда-нибудь начнёт моделировать реальные биржевые заявки, их изменяемый жизненный цикл должен принадлежать отдельной сущности `Order`. Исполнение заявок сейчас находится за границей Investment Ledger.

## Проверенные сценарии

| Сценарий | Существует ли Operation |
|---|---|
| Команда содержит количество `0` | Нет: команда отклоняется на validation |
| Для покупки недостаточно денег | Нет: команда получает business rejection |
| Хранилище отказало до append | Нет |
| Append завершился, но ответ потерялся | Да: повтор должен вернуть сохранённый результат |
| Принятую покупку позднее компенсировали | Да: существуют исходная и компенсирующая операции |
